# 🔑 幻界之鑰 — Unity 第三人稱 ARPG 專題遊戲

> 此專案為資策會「Unity互動程式開發工程師養成班」結訓專題，由第五組開發完成。靈感來自《原神》，是一款結合探索、戰鬥與角色切換機制的第三人稱動作角色扮演遊戲。

---

## 🎮 遊戲介紹

- 類型：第三人稱動作 RPG
- 引擎：Unity 2022.3
- 參考遊戲：《原神》

---

## 🧩 主要功能特色

### 🧍 玩家控制系統
- 使用 Singleton 管理角色容器與多角色切換
- 第三人稱自由攝影機追蹤
- 動畫狀態機（Animator）+ C# FSM 控制角色行為（Idle / Walk / Run / Jump / Attack）

### ⚔️ 戰鬥系統
- 使用 Animation Event 搭配 OverlapSphere 進行攻擊偵測
- IDamageable interface 解耦傷害判定
- 使用 Delegate 機制讓中毒、音效、特效等效果可插拔式反應

### 🧠 敵人 AI 系統
- 自製有限狀態機 FSM（Idle → Chase → Attack → GotHit → Dead）
- 扇形視野判斷（視角 + 距離）決定是否追擊玩家
- 玩家切換或從背後偷襲將觸發敵人警覺

### 👥 多敵人碰撞避免
- 實作簡易 Avoidance 函式，當敵人彼此靠近距離 < 1 時，產生向外推力防止重疊

### 🗝️ 關卡與事件流程
- 玩家靠近寶箱 → 敵人出現 → 防護罩升起
- 擊敗所有敵人 → 防護罩解除 → 可互動取得寶物 → 加入背包

## 📦 技術應用與架構特色

- Unity 2022.3 LTS
- C# 面向物件設計、策略模式與狀態機模式
- Interface + Delegate 模組化架構
- ScriptableObject 管理角色資料與裝備資訊
- Cinemachine 處理跟隨攝影機
- Git 分支協作管理
